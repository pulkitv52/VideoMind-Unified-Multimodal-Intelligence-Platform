# Small road-video starter pack

Checked 18 October 2026. Five Wikimedia Commons original WebM files total
99,342,611 bytes (94.74 MiB). Each original fits the current 64 MiB file limit.
This is a curated demonstration collection, not a labeled academic benchmark.

Exact media URLs, original-page links, creators, licenses, byte counts and SHA-1
values are in [road-video-starter.json](road-video-starter.json). Metadata came
from the official Commons `imageinfo` API and the linked file description pages.
The byte counts and checksums are publisher metadata, not local download results.

Preserve these originals. Create MP4 derivatives if required by the uploader;
record their checksum, conversion command, producer version and mapping to the
original. Credit the creator, title, file-page source and license. Mark conversion
or trimming explicitly; keep shared adaptations of the BY-SA files under the
same or a compatible license. Use the original creator/source links in the JSON
alongside the Commons attribution page. No YouTube or Vimeo extraction is needed:
the media downloads are from Wikimedia's own upload host.

Descriptions are selection hints based on Commons descriptions and categories,
not ground-truth event labels or measured time intervals. In particular the
highway clip is a timelapse; its playback clock cannot establish real driving
speed or real-world event duration. Inspect representative frames before adding
evaluation questions. These samples test intake and format handling now; they
do not establish semantic retrieval quality before indexing exists.

## Alternatives reviewed

The [UZH RPG driving dataset](https://rpg.ifi.uzh.ch/event_driving_datasets.html)
offers small windshield RGB MP4s and requests a research citation, but the page
does not specify an explicit media reuse license. It was not selected for this
pack. The [KITTI raw download page](https://www.cvlibs.net/datasets/kitti/raw_data.php)
requires login; no login or bypass was attempted. Commons files were selected
instead because their individual media access and stated reuse terms are clear.
